## 修复微信登录报错（纯静态部署无后端时登录失败）
- 问题：Login.tsx 调 `login()` → `apiClient.post('/auth/login')` 请求后端；GitHub Pages 是纯静态站没有后端，请求失败 → 报「登录失败，请稍后再试」。
- 修复1：`api.ts` 的 `login()` 加 try/catch，请求失败时回退本地模拟登录，生成 `local_` 前缀 token + 本地 user（name 用手机尾号/微信标识），登录态写入 localStorage。
- 修复2：`AppStore.tsx` 启动校验 token 时，仅当后端明确返回无效（user===null）且 token 非 `local_` 前缀才踢出登录；网络错误/无后端时保留本地登录态，避免刷新后被登出。
- 本地预览：`cd frontend && pnpm dev --host`，访问 http://localhost:5173/storybook/（base 是 /storybook/，根路径会 302 跳转）。
- 已用 agent-browser 验证：点「微信一键登录」→ 跳 /history + 提示「欢迎，微信用户xxxx」+ 头部出现「历史」链接，登录态生效。
- 注：登录逻辑仍是「无真实验证码」的演示态，本地模拟登录只在前端 localStorage 层面，不做云端同步。
