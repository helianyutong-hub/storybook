### 部署到 GitHub（已完成）
- 仓库：github.com/helianyutong-hub/storybook（按用户选择设为 **公开**，因 GitHub Pages 免费版不支持私有仓库开页面）。
- 在线链接（GitHub Pages）：https://helianyutong-hub.github.io/storybook/
- 部署方式：前端 `vite base:'/storybook/'`，构建产物推 `gh-pages` 分支，API `POST /repos/{o}/{r}/pages` 开启；首次构建可能 errored，重触发一次即可。
