音色列表官方文档：https://help.aliyun.com/zh/model-studio/cosyvoice-voice-list

### 关键实现点

- **双端点 × 双音色 = 4 种降级组合**：
  端点①`https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api/v1/services/audio/tts/SpeechSynthesizer`
  （voice 放在 `input` 里）；端点②`https://dashscope.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation`
  （voice 放在 `parameters` 里）。配了 WorkspaceId 就优先走①。
  每个音色还配了 fallback，主音色不可用自动降级。
- **401/403 直接放弃阿里云**（换端点换音色都没用），回退 Edge TTS。
- **缓存 key 带引擎名** `${ttsProvider()}:${lang}:${voice}:${text}`，切换服务商后旧音频自动失效。
- **官方已知问题处理**：cosyvoice-v3-flash 遇「·」会漏读 → 替换为中文逗号；文本截断 2000 字。
- **自检端点** `GET /api/tts/provider` 返回当前引擎、是否已配置 Key、每个音色对应关系。
- 成本：1 元/万字符，免费额度 1 万字符（90 天）。一个故事约 800 字 ≈ 0.08 元。

### Dockerfile 支持国内镜像源

```dockerfile
ARG NPM_REGISTRY=https://registry.npmjs.org
ENV NPM_CONFIG_REGISTRY=$NPM_REGISTRY
```

- 境外（Render/Railway）不传参数 = 官方源，行为不变
- 国内服务器：`docker compose build --build-arg NPM_REGISTRY=https://registry.npmmirror.com`

## 微信播放页 3 项兼容性彻底修复（2026-09-04 晚，main `f658c1ba`）

用户微信实测反馈：之前修的 3 个问题仍然没好——①返回预览没反应 ②X 关闭没反应 ③暂停图标不变▶。
**根因分析**：
- 导航问题：`exitToPreview` 用 React Router `nav()` 做主路径，微信浏览器 SPA 路由经常不触发实际页面跳转；300ms 后的 `window.location.href` 兜底可能被状态重渲染拦截
- 暂停图标：`togglePlay` 虽然显式 `setPlaying(false)`，但 `<audio>` 的 `onPlay` 事件或加载 effect 可能在 `pause()` 之后异步又把 `playing` 设回 true，覆盖用户意图

**本轮修复（更激进的微信兼容方案）**：
1. **导航**：`exitToPreview` 放弃 `nav()`，直接用 `window.location.href = target`（最可靠）
2. **暂停锁**：新增 `pausedByUserRef`——用户点暂停时加锁，`onPlay` 事件和加载 effect 检测到锁存在就跳过自动恢复 `playing=true`；用户再点播放时清锁
3. `togglePlay` / `restart` / `exitToPreview` 三处均正确管理锁的生命周期

**状态**：本地已提交（`f658c1ba`），构建通过（新包 `index-D2g0RFhr.js`），dev server 热更新中。**未发版**，等用户本地预览确认。
