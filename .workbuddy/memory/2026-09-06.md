# 2026-09-06 故事书（storybook）

## 插画老故事兼容：缺失 friendKind 时按文案/角色推断动物（2026-09-06 00:05）

### 问题
之前几轮把新故事的 `illustration.friendKind` 字段补齐后，新故事能按角色画对应动物。但**线上/本地已有老故事**（改版前生成的 `illustration` 没有 `friendKind`），预览页/播放页仍按原来的 `pickKindFromElements` 推断：elements 里只有 moon/cloud/firefly 时能命中，其它情况一律兜底画小熊，导致"文案说小鹿，画面还是小熊"。

### 改动
- `frontend/src/types/story.ts`：`IllustrationSpec.friendKind` 注释说明，语义不变。
- `frontend/src/lib/illustration.tsx`：
  - `StoryIllustration` 新增可选 props：`characters`（故事级角色列表）、`scene`（当前页场景）、`pageText`（当前页文案）。
  - 新增 `inferKindFromContext(characters, scene, pageText, elements)`：
    1. 先扫 `scene + pageText` 里的动物关键词（小鹿/小兔/小熊/小狐狸/小猫/小鸭/鲸鱼/星星/月亮/云朵/大树/萤火虫等）。
    2. 未命中则按 `characters` 第一个通过 `kindFromName` 查表/关键词匹配。
    3. 还搞不定才退化到 `pickKindFromElements`（保持向后兼容）。
  - `kind: AnimalKind` 的取值改为 `spec.friendKind ?? (hasFriend ? inferKindFromContext(...) : 'bear')`。
- `frontend/src/lib/storyEngine.ts`：确保 `kindFromName` 已 export，供 `illustration.tsx` 导入。
- `frontend/src/pages/Player.tsx`：调用 `StoryIllustration` 时传入 `characters / scene / pageText`。
- `frontend/src/components/StorybookViewer.tsx`：调用 `StoryIllustration` 时传入 `story.params.characters / page.scene / page.text`。
- `frontend/src/pages/Home.tsx`：首页 SAMPLE 示例插画增加显式 `friendKind: 'bear'`，让首屏展示的小动物稳定与下方文案"小熊轻轻坐在她身边"一致。
