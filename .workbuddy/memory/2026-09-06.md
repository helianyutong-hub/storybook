## 插画老故事兼容：缺失 friendKind 时按文案/角色推断动物（2026-09-06 00:05）

### 问题
之前几轮把新故事的 `illustration.friendKind` 字段补齐后，新故事能按角色画对应动物。但**线上/本地已有老故事**（改版前生成的 `illustration` 没有 `friendKind`），预览页/播放页仍按原来的 `pickKindFromElements` 推断：elements 里只有 moon/cloud/firefly 时能命中，其它情况一律兜底画小熊，导致"文案说小鹿，画面还是小熊"。

### 改动
- `frontend/src/types/story.ts`：`IllustrationSpec.friendKind` 注释说明，语义不变。
- `frontend/src/lib/illustration.tsx`：
  - `StoryIllustration` 新增可选 props：`characters`（故事级角色列表）、`scene`（当前页场景）、`pageText`（当前页文案）。
  - 新增 `inferKindFromContext(characters, scene, pageText, elements)`：
    1. 先扫 `scene + pageText` 里的动物关键词（小鹿/小兔/小熊/小狐狸/小猫/小鸭/鲸鱼/星星/月亮/云朵/大树/萤火虫等）。
    2. 未命中则按 `characters` 第一个通过 `kindFromName` 查表/关键词匹配。
    3. 还搞不定才退化到 `pickKindFromElements`（保持向后兼容）。
  - `kind: AnimalKind` 的取值改为 `spec.friendKind ?? (hasFriend ? inferKindFromContext(...) : 'bear')`。
- `frontend/src/lib/storyEngine.ts`：确保 `kindFromName` 已 export，供 `illustration.tsx` 导入。
- `frontend/src/pages/Player.tsx`：调用 `StoryIllustration` 时传入 `characters / scene / pageText`。
- `frontend/src/components/StorybookViewer.tsx`：调用 `StoryIllustration` 时传入 `story.params.characters / page.scene / page.text`。
- `frontend/src/pages/Home.tsx`：首页 SAMPLE 示例插画增加显式 `friendKind: 'bear'`，让首屏展示的小动物稳定与下方文案"小熊轻轻坐在她身边"一致。

### 验证
- `npm run build` 通过，无 TS 错误。
- Playwright 注入两组老故事数据（illustration 无 friendKind 字段）：
  - `characters=['小鹿']` + 文案"小鹿走到月光下/踏过小溪/走进树林" → p0/p1/p2 均正确显示小鹿（带分叉鹿角）。
  - `characters=[]` + 文案"一只小狐狸追着萤火虫跑" → 正确显示狐狸；文案"月亮婆婆在云上看着它们" → 正确显示月亮婆婆。

## 创作页：自定义角色池 + 删除 + SVG 识别；新增猴子 SVG（2026-09-06 00:40）

### 问题
用户反馈：
1. 创作页自定义添加的角色没有取消入口。
2. 新增内容最好有地方显示，能选中和取消选中。
3. 新增的内容要能删除（系统默认的可不删）。
4. 新增动物/植物关键词时，系统自动识别文案并显示对应 SVG 插画。

### 改动
- `frontend/src/components/CharacterPicker.tsx`：
  - 新增 `customPool` state：用户添加过的自定义角色会保留在"已添加的自定义角色"区，即使取消选中也不会消失，可反复点选。
  - 自定义角色 tag 可点击切换选中/取消，右侧 × 按钮可删除（从 `customPool` 和 `value` 同时移除）。
  - 系统默认角色仍只支持选/取消，没有删除。
  - 新增"角色预览"区：每个已选角色通过 `kindFromName` 自动识别动物类型，渲染 `StoryIllustration` mini SVG，识别成功显示"已识别"，否则显示"通用形象"。
  - 新增 `hashName` 让同名字预览图稳定一致。
- `frontend/src/types/story.ts`：`AnimalKind` 新增 `'monkey'`。
- `frontend/src/lib/illustration.tsx`：
  - 新增 `MonkeyFriend` SVG 组件（圆耳 + 圆脸 + 弯弯尾巴 + 棕色）。
  - `KIND_PALETTE` 加 monkey 配色（`body: '#c49a6c'`, `accent: '#ffe4b0'`）。
  - `Friend` switch 增加 `'monkey'` 分支。
  - `inferKindFromContext` 关键词列表加 `小猴子/猴子/猴`。
- `frontend/src/lib/storyEngine.ts`：
  - `CHAR_TO_KIND` 加 `小猴子: 'monkey'`。
  - `kindFromName` 关键词匹配加 `/猴/` → `'monkey'`。

### 验证
- `npm run build` 通过，无 TS 错误。
- Playwright 验证：
  - 添加"小猴子/小白兔/梅朵朵" → "已添加的自定义角色"区显示 3 个 tag。
  - 点击"小猴子" tag 主体取消选中 → tag 变灰但仍在池子里。
  - 再次点击"小猴子" → 重新选中。
  - 点击"梅朵朵"的 × → 从池子和已选中同时删除。
  - 角色预览区：小猴子/小白兔显示"已识别"，梅朵朵显示"通用形象"。
  - 生成故事（只选小猴子）→ preview 第 2 页插画正确显示猴子形象，且 story.pages 的 illustration.friendKind 全为 `'monkey'`。
