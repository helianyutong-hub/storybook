# 故事书部署到阿里云（大白话步骤）

> 适用：已有阿里云服务器（ECS / 轻量应用服务器）+ 已备案域名，前后端都搬、用同一个域名访问。
> 下面以 **Ubuntu 20.04/22.04** 为例；CentOS 把 `apt` 换成 `yum/dnf` 即可，文末有备注。

---

## 先填好这两样
- 备案域名：________（例如 `story.yourname.com`）
- 服务器公网 IP：________

---

## 第一步：域名解析（DNS）
登录阿里云控制台 → 云解析 DNS → 你的域名 → 添加记录：
- 记录类型：`A`
- 主机记录：`story`（想要 `story.域名` 就用 story；想用根域名就用 `@`）
- 记录值：填你的**服务器公网 IP**
- TTL：10 分钟

---

## 第二步：登录服务器，装 Docker
```bash
ssh root@你的服务器IP

# Ubuntu 一键装 Docker + Compose（阿里云镜像加速）
curl -fsSL https://get.daocloud.io/docker | bash -s docker --mirror Aliyun
sudo systemctl enable --now docker
docker --version
```

---

## 第三步：把代码弄到服务器并起后端
```bash
# 方式 A：服务器能直接访问 GitHub（仓库是公开的最简单）
git clone https://github.com/helianyutong-hub/storybook.git
cd storybook/backend
docker compose up -d --build

# 起来后看一眼日志，确认没报错
docker logs -f storybook-backend
```
> 方式 B（私有仓库 / 不想公开）：在你本机把 `backend/` 整个文件夹打成 zip，用 `scp` 传上去再解压，然后同样 `docker compose up -d --build`。

后端会用 Docker 跑在 `127.0.0.1:3000`，只对本机开放（安全），外面靠 nginx 反代。

---

## 第四步：构建前端
```bash
# 服务器上装 Node 20
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt-get install -y nodejs

cd storybook/frontend
npm install
npm run build

# 把构建产物放到 nginx 要托管的位置
mkdir -p /var/www/storybook
cp -r dist/* /var/www/storybook/
```

---

## 第五步：装 Nginx + 配置反代
```bash
apt-get install -y nginx
```

把仓库里的 `deploy/nginx.conf` 传到服务器 `/etc/nginx/conf.d/storybook.conf`，
**把里面所有 `YOUR_DOMAIN` 替换成你的真实域名**，然后：
```bash
nginx -t            # 校验配置（这一步证书还没申请，先会报 SSL 文件不存在，正常）
```

👉 由于证书还没申请，先临时只保留 HTTP 部分：
把 `storybook.conf` 里 `listen 443 ssl;` 那一段（整个第二个 server 块）先注释掉，
只留 80 端口那段，执行：
```bash
nginx -t && systemctl reload nginx
```
这时用 `http://你的域名` 应该能看到页面（语音还走不了 HTTPS，先验证页面在）。

---

## 第六步：申请免费 SSL 证书（微信必须 HTTPS）
```bash
apt-get install -y certbot python3-certbot-nginx

# 标准方式：certbot 自动帮你改 nginx 配置、加 443、续期
certbot --nginx -d 你的域名
```
按提示选「Redirect」让它自动把 80 跳 443。

> 如果你用阿里云控制台自带的**免费 DV 证书**：下载 Nginx 版（含 .pem 和 .key），
> 传到 `/etc/nginx/ssl/`，再取消注释 `storybook.conf` 里 443 那段，
> 把 `ssl_certificate` / `ssl_certificate_key` 路径改成你传的文件，然后 `nginx -t && systemctl reload nginx`。

---

## 第七步：开防火墙端口
阿里云控制台 → 安全组 → 入方向规则，放通：
- `80` 端口（HTTP）
- `443` 端口（HTTPS）
- `22` 端口（SSH，默认已有）

---

## 第八步：验证
浏览器打开 `https://你的域名`：
1. 能正常打开、生成故事 ✅
2. 点「试听 / 播放」能出声（首次生成要等几十秒，因为 edge-tts 连微软境外）✅
3. 手机微信里打开也能正常播放 ✅

---

## 日常维护
- 改了后端代码：服务器上 `cd storybook/backend && git pull && docker compose up -d --build`
- 改了前端代码：重新 `npm run build` 再 `cp -r dist/* /var/www/storybook/`
- 看后端日志：`docker logs -f storybook-backend`
- 证书续期：certbot 自动续，可手动试 `certbot renew --dry-run`

---

## CentOS 差异备注
- 装 Docker：`sudo yum install -y docker` 然后 `sudo systemctl enable --now docker`
- 装 Nginx：`sudo yum install -y nginx`；启动 `sudo systemctl enable --now nginx`
- 装 Node：用 `nvm` 或官网二进制；certbot 用 `sudo yum install -y certbot python3-certbot-nginx`
- 其余步骤完全一样
