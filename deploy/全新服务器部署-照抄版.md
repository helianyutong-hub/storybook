# 全新服务器部署（照抄版）

> 适用：阿里云新买的空服务器 + 已有备案域名。  
> 全程复制粘贴命令就行，不用懂 Linux。  
> 预计 40 分钟，其中大部分时间在等它自己跑。

---

## 开始前：先把这 4 个空填上

先把这几个东西找出来，填在下面，后面直接对着抄：

| 要填什么        | 你的值           | 去哪找                                   |
| ----------- | ------------- | ------------------------------------- |
| 服务器公网 IP    | `________`    | 阿里云控制台 → 云服务器 ECS → 实例列表              |
| 服务器 root 密码 | `________`    | 自己设的。忘了就控制台 → 实例 → **重置实例密码**，改完要重启实例 |
| 备案域名        | `________`    | 例如 `story.yourname.com`               |
| 阿里云语音 Key   | `sk-________` | 第 4 步去拿，先空着                           |

---

## 第 0 步：先确认服务器系统（10 秒）

后面命令分 Ubuntu 和 CentOS 两套，先确认你是哪个。

**Mac 上打开终端**：按 `Command + 空格`，输入 `终端`，回车。

连上服务器（把 IP 换成你的）：

```bash
ssh root@你的服务器IP
```

- 第一次连会问 `Are you sure you want to continue connecting`，输入 `yes` 回车
- 然后要你输密码：**输入时屏幕上什么都不显示，这是正常的**，输完直接回车就对了

连上后你会看到类似 `root@iZbp1xxxx:~#` 这样的提示符，说明进去了。

然后看系统版本：

```bash
cat /etc/os-release | head -3
```

**看到 `Ubuntu` 就照着本文一路走下去。**  
如果看到 `CentOS` 或 `AlmaLinux`，在文末「CentOS 用户看这里」有对应的替换命令。

---

## 第 1 步：装 Docker（3 分钟）

下面这段是 Ubuntu 的一键脚本，**整段复制粘贴**进去回车：

```bash
curl -fsSL https://get.daocloud.io/docker | bash -s docker --mirror Aliyun
```

跑完再执行这两行：

```bash
systemctl enable --now docker
docker --version
```

**看到 `Docker version 2x.x.x` 就成了。**  
如果报错说找不到 curl，先跑 `apt-get update && apt-get install -y curl` 再重试。

---

## 第 2 步：域名解析（在阿里云网页上点，2 分钟）

这一步是在阿里云控制台操作，不是敲命令。

1. 打开 **阿里云控制台 → 云解析 DNS**
2. 点你的域名进去 → **添加记录**
3. 填这四项，其他默认：

| 字段   | 填什么                                      |
| ---- | ---------------------------------------- |
| 记录类型 | `A`                                      |
| 主机记录 | 想要 `story.你的域名` 就填 `story`；想直接用根域名就填 `@` |
| 记录值  | **你的服务器公网 IP**                           |
| TTL  | 10 分钟                                    |

1. 保存

**验证解析好了没**（回到终端，把域名换成你的）：

```bash
ping -c 2 你的域名
```

看到 IP 是你服务器的 IP 就对了。（`ping` 不通也别慌，有些服务器禁 ping，只要显示的 IP 对就行）

> 如果显示的 IP 不对，等 10 分钟再试，刚加的记录要等一会儿生效。

---

## 第 3 步：装 Nginx（1 分钟）

```bash
apt-get update
apt-get install -y nginx
systemctl enable --now nginx
```

**验证**：浏览器打开 `http://你的域名`，看到 **Welcome to nginx** 页面就成了。

看不到的话，先去阿里云控制台 → **安全组** → 入方向，确认 80 端口放开了（第 9 步有详细图示说明）。

---

## 第 4 步：去拿阿里云语音 Key（在网页上点，3 分钟）

1. 打开 **<https://bailian.console.aliyun.com/>** ，用阿里云账号登录
2. 第一次进会让你**开通百炼**，点开通（免费，不花钱）
3. 开通后，点右上角**头像 → API-KEY**
4. 点 **创建新的 API-KEY**，生成一串 `sk-xxxxxx`
5. **复制下来，先粘到本文开头那个表格里存着**

⚠️ **一定要选「华北 2（北京）」地域的 Key**，其他地域用不了语音合成。

> 这一步不做也行，部署照常，只是四个音色听起来差不多。回头想补，改个配置文件重启就行，见文末。

## 第 5 步：把后端搬到服务器 + 填 Key + 启动（5 分钟）

### 5.1 下载代码

```bash
cd /root
git clone https://github.com/helianyutong-hub/storybook.git
cd storybook/backend
```

> ⚠️ **git clone 拉的是 GitHub 上的版本，不是你电脑上的**。  
> 如果你电脑上刚改过代码还没推送到 GitHub，服务器是拉不到的。  
> 需要先在自己电脑的终端里执行：
>
> ```bash
> cd /Users/luoyuanyu/WorkBuddy/实操项目-mine && git push origin main
> ```
>
> 不确定有没有推送过？执行 `git status`，看到  
> `Your branch is ahead of 'origin/main'` 就说明有改动没推送。

> **如果卡住不动或报错**（国内服务器访问 GitHub 有时会）：  
> 按 `Ctrl + C` 中断，改用上传方式 —— 见文末「GitHub 拉不下来怎么办」。  
> 这个方式打包的是**你电脑上的代码**，不受有没有推送影响，其实更保险。

### 5.2 写配置文件 + 填 Key

**重点：不要用 vi**（进去容易出不来）。直接复制下面整段，把 `sk-你的密钥` 换成第 4 步拿到的真 Key，然后整段粘贴回车：

```bash
cat > /root/storybook/backend/.env <<'EOF'
NODE_ENV=production
PORT=3000
API_PREFIX=/api
CORS_ORIGIN=*
LOG_LEVEL=info
DASHSCOPE_API_KEY=sk-你的密钥
EOF
```

写完确认一下填对了没：

```bash
cat /root/storybook/backend/.env
```

**最后一行应该是 `DASHSCOPE_API_KEY=sk-xxx...`，Key 完整、没有换行、没有多余空格。**

> 写错了就重新跑一遍上面那段 `cat > ...` 命令，会整个覆盖重写，没事。

### 5.3 启动后端

```bash
cd /root/storybook/backend
docker compose build --build-arg NPM_REGISTRY=https://registry.npmmirror.com && docker compose up -d
```

> 命令里那一长串是指定**国内镜像源**，比默认的境外源快很多（境外平台如 Render 才需要默认源）。

**这一步要等 5-10 分钟**，它在下载依赖和打包。你会看到一堆滚动的日志，不动了就是好了。

> **如果卡在某一行超过 15 分钟完全没反应**，按 `Ctrl + C` 中断，  
> 把命令里的 `https://registry.npmmirror.com` 换成 `https://mirrors.cloud.tencent.com/npm/`，再跑一次。

跑完看一眼是否成功：

```bash
docker ps
```

**看到一行里有 `storybook-backend`，且 STATUS 是 `Up xxx秒` 就成了。**

如果是 `Restarting` 或者列表里没有，说明挂了，看日志：

```bash
docker logs storybook-backend --tail 30
```

### 5.4 验证后端活了

```bash
curl http://127.0.0.1:3000/api/health
```

**看到 `{"status":"ok"}` 之类的返回就成了。**

再看语音 Key 有没有读到：

```bash
curl http://127.0.0.1:3000/api/tts/provider
```

**重点看 `"configured"` 这一项：**

- `"configured": true` → Key 读到了 ✅
- `"configured": false` → 没读到，回去检查 5.2 那个文件

## 第 6 步：构建前端（在你自己电脑上做，5 分钟）

**前端在你自己电脑上打包好再传上去**，比在服务器上装 Node 快得多，也不容易失败。

### 6.1 打开 Mac 上的新终端窗口

**不要关掉连服务器的那个窗口**，再开一个新的：  
按 `Command + N`（在终端里），会弹出新窗口。

### 6.2 打包

```bash
cd /Users/luoyuanyu/WorkBuddy/实操项目-mine/frontend
npm install
npm run build
```

> `npm install` 第一次要几分钟。如果报网络错误，把命令换成  
> `npm install --registry=https://registry.npmmirror.com` 再跑。

跑完会看到 `built in xx s`，说明好了。

### 6.3 上传到服务器

先在服务器上建好文件夹（回到**连服务器的那个终端窗口**，或者在新窗口里 ssh 也行）：

```bash
mkdir -p /var/www/storybook
```

然后回到**本机终端**（刚才打包的那个窗口），把 IP 换成你的，执行：

```bash
scp -r /Users/luoyuanyu/WorkBuddy/实操项目-mine/frontend/dist/* root@你的服务器IP:/var/www/storybook/
```

要输密码就输服务器的 root 密码（同样不显示，输完回车）。

**验证传上去了**（回服务器窗口）：

```bash
ls /var/www/storybook/
```

**看到 `index.html` 和 `assets` 文件夹就成了。**

---

## 第 7 步：配置 Nginx 反向代理（2 分钟）

在**服务器终端**里，整段复制下面这段，**记得把两个 `你的域名` 都换成真实域名**（一共出现 2 处）：

```bash
cat > /etc/nginx/conf.d/storybook.conf <<'EOF'
server {
    listen 80;
    server_name 你的域名;

    root /var/www/storybook;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 120s;
    }
}
EOF
```

然后让 Nginx 重新加载配置：

```bash
nginx -t && systemctl reload nginx
```

**看到 `syntax is ok` 和 `test is successful` 就成了。**（有 `warn` 警告不用管）

如果报 `nginx: [emerg]` 这种红色错误，说明配置文件写坏了 —— 大概率是域名那行没替换，或者多了少了括号。重新跑一遍上面那段 `cat > ...` 命令覆盖掉。

**验证**：浏览器打开 `http://你的域名`，应该能看到故事书的页面了（这时还是 http，下一步上 https）。

---

## 第 8 步：申请免费 HTTPS 证书（3 分钟）

微信里打开必须 HTTPS，所以这步不能省。

```bash
apt-get install -y certbot python3-certbot-nginx
certbot --nginx -d 你的域名
```

会问你几个问题：

| 问什么              | 怎么答                                      |
| ---------------- | ---------------------------------------- |
| 邮箱               | 填你自己的邮箱（证书快过期会提醒你）                       |
| 同意服务条款           | 输入 `a` 回车（Agree）                         |
| 是否分享邮箱           | 输入 `n` 回车                                |
| 是否重定向 HTTP→HTTPS | **选 `2`（Redirect）**，这样访问 http 会自动跳 https |

**看到 `Congratulations! You have successfully enabled HTTPS` 就成了。**

> **如果报 `Failed authorization` / `Timeout`**，多半是第 2 步域名解析还没生效，或者 80 端口没开。  
> 回去 `ping 你的域名` 确认 IP 对不对，再去安全组确认 80 和 443 都放开了，然后重跑一遍命令。

证书 90 天过期，certbot 会自动续，不用管。

---

## 第 9 步：开防火墙端口（2 分钟，在阿里云网页上点）

1. 阿里云控制台 → **云服务器 ECS** → 点你的实例
2. 点 **安全组** 标签 → 点安全组名字进去
3. 点 **入方向 → 手动添加**，加这三条：

| 端口范围      | 授权对象        | 说明                |
| --------- | ----------- | ----------------- |
| `80/80`   | `0.0.0.0/0` | HTTP              |
| `443/443` | `0.0.0.0/0` | HTTPS             |
| `22/22`   | `0.0.0.0/0` | SSH（一般默认已有，没有就加上） |

---

## 第 10 步：验收

浏览器打开 \*\*<https://你的域名\*\*，检查这> 5 项：

- [ ] 页面能正常打开，不是 nginx 欢迎页
- [ ] 生成一个故事，能正常出内容
- [ ] 打开 `https://你的域名/api/tts/provider`，看到 `"configured": true`
- [ ] 点播放能出声，**换不同音色（宝爸/宝妈/爷爷/奶奶）能明显听出区别**
- [ ] 用手机微信打开也能正常播放

全过了就部署完成了 🎉

## 出问题怎么办

| 现象                                         | 原因            | 怎么修                                                                   |
| ------------------------------------------ | ------------- | --------------------------------------------------------------------- |
| `/api/tts/provider` 显示 `configured: false` | Key 没填或填错     | 重跑第 5.2 步，然后 `docker compose restart`                                 |
| 页面能开，但生成故事报错                               | 后端没起来         | `docker ps` 看看容器在不在，不在就 `docker logs storybook-backend --tail 30` 看报错 |
| 语音播放不出来                                    | 后端挂了，或 Key 失效 | 先看 `/api/tts/provider`，再看 `docker logs`                               |
| 换了音色但声音没变                                  | 有缓存           | `rm -rf /root/storybook/backend/data/tts/*.mp3`                       |
| 浏览器显示不安全                                   | 证书没申请成功       | 重跑第 8 步的 `certbot` 命令                                                 |
| SSH 连不上                                    | 22 端口没开，或密码错了 | 检查安全组；密码去控制台重置（改完要重启实例）                                               |

**一键自检**：把这几条挨个跑一遍，把输出发给我，我帮你定位：

```bash
docker ps
curl http://127.0.0.1:3000/api/health
curl http://127.0.0.1:3000/api/tts/provider
ls /var/www/storybook/
nginx -t
```

## 特殊情况处理

### CentOS 用户看这里

第 1 步装 Docker 换成：

```bash
yum install -y docker
systemctl enable --now docker
```

第 3 步装 Nginx 换成：

```bash
yum install -y nginx
systemctl enable --now nginx
```

第 8 步装 certbot 换成：

```bash
yum install -y certbot python3-certbot-nginx
```

其他步骤完全一样。

### GitHub 拉不下来怎么办（第 5.1 步的备选）

在**你自己的电脑**上打包后传上去：

```bash
cd /Users/luoyuanyu/WorkBuddy/实操项目-mine
zip -r backend.zip backend -x "*/node_modules/*" -x "*/data/*"

# 传到服务器
scp backend.zip root@你的服务器IP:/root/
```

然后回到**服务器终端**：

```bash
cd /root
apt-get install -y unzip        # CentOS 用 yum install -y unzip
unzip backend.zip
rm backend.zip
cd backend
```

然后接着做 5.2 步就行（路径变成 `/root/backend/.env`）。

### 想先不配 Key 试试

第 5.2 步那个 `cat > ...` 命令里，把最后一行 `DASHSCOPE_API_KEY=sk-你的密钥` 删掉就行，  
其他完全一样。之后想补，随时重跑那段命令加上去，再 `docker compose restart`。
