# 语音合成换成阿里云 CosyVoice

## 为什么要换

之前用的是微软 Edge TTS（免费），但它**只有 4 个中文音色**，所谓"宝爸/宝妈/爷爷/奶奶"其实只是把同一个声音调高调低了音调（pitch），所以听起来几乎一样。

换成阿里云 CosyVoice 后，四个角色是**不同年龄、不同性别的真实音色**，一听就能分辨：

| 角色 | 阿里云音色 | voice 参数 | 声音特征 | 年龄 |
|---|---|---|---|---|
| 宝妈 | 龙婉君 | `longwanjun_v3` | 细腻柔声女（有声书专用） | 20-30 岁 |
| 宝爸 | 龙安昀 | `longanyun_v3` | 居家暖男 | 30-35 岁 |
| 爷爷 | 龙老伯 | `longlaobo_v3` | 沧桑岁月爷 | 60 岁以上 |
| 奶奶 | 龙老姨 | `longlaoyi_v3` | 烟火从容阿姨 | 60 岁以上 |

> 音色参数来自官方文档：https://help.aliyun.com/zh/model-studio/cosyvoice-voice-list
> 每个音色都配了备用音色，主音色不可用时自动降级，不会整个功能挂掉。

**所以音色选择功能保留了。**

---

## 一、开通服务 & 拿 API Key（约 5 分钟）

1. 打开 **https://bailian.console.aliyun.com/** ，用阿里云账号登录
2. 第一次进会提示**开通百炼服务**，点开通（免费开通，不花钱）
3. 开通后，点右上角头像 → **API-KEY**
   （或直接访问 https://bailian.console.aliyun.com/?tab=model#/api-key ）
4. 点 **创建新的 API-KEY**，生成一串 `sk-xxxxxx` 的密钥，**复制保存好**

⚠️ 注意：要选**华北 2（北京）**地域的 API Key，CosyVoice 目前只支持北京地域。

---

## 二、配置到后端（1 分钟）

按后端跑在哪里，选一条走。

### 路径 A：后端跑在 Render 上（**当前就是这个**）

现在线上用的后端是 `storybook-backend-wxxs.onrender.com`，在网页上填就行，不用碰服务器：

1. 打开 https://dashboard.render.com/ ，点 **storybook-backend**
2. 左侧菜单点 **Environment**
3. 找到（或点 **Add Environment Variable** 新增）这一项：
   - **Key**：`DASHSCOPE_API_KEY`
   - **Value**：`sk-你刚才复制的密钥`
4. 点 **Save Changes**

Render 会自动重启服务，等 1-2 分钟变绿。

> 想更稳的话可以再加一项 `DASHSCOPE_WORKSPACE_ID`（百炼控制台左下角「工作空间」里能看到），配了走 CosyVoice 专用端点。不配也能用。

### 路径 B：后端跑在阿里云服务器 / 自己机器上

在 `backend/` 目录编辑 `.env`（没有就从模板复制）：

```bash
cp .env.example .env
```

加入这一行：

```env
DASHSCOPE_API_KEY=sk-你刚才复制的密钥
```

**可选配置**（不配也能用）：

```env
# 百炼控制台的 WorkspaceId，配了走 CosyVoice 专用端点，更稳
DASHSCOPE_WORKSPACE_ID=

# 语音模型，默认就是 cosyvoice-v3-flash，一般不改
ALIYUN_TTS_MODEL=cosyvoice-v3-flash
```

如果用 Docker Compose 部署，`docker-compose.yml` 里已经配好透传了，`.env` 里填上就会自动带进容器。

然后重启后端：

```bash
docker compose up -d --build
# 或者非 Docker：pm2 restart 你的进程名
```

## 三、验证是否生效

**方法 1：打开自检地址**

浏览器访问（把域名换成你自己的）：

```
https://你的域名/api/tts/provider
```

现在线上那个后端，直接点这个：
https://storybook-backend-wxxs.onrender.com/api/tts/provider

看到 `"provider": "aliyun"` 且 `"configured": true` 就成了：

```json
{
  "provider": "aliyun",
  "configured": true,
  "model": "cosyvoice-v3-flash",
  "voices": {
    "grandpa": { "voice": "longlaobo_v3", "desc": "沧桑岁月爷 60岁以上" }
  }
}
```

如果还是 `"configured": false`，说明 Key 没读到 —— 检查 Render 上变量名拼对了没（`DASHSCOPE_API_KEY`，不是 `DASH_SCOPE`），改完要等它重启完再看。

> Render 免费版一段时间没人访问会休眠，第一次打开可能要等 30-60 秒才响应，不是坏了。

**方法 2：直接去 App 里生成一个故事听**

选不同的音色各生成一页，对比听一下就能听出差别。

## 四、费用说明

| 项目 | 数值 |
|---|---|
| 单价 | **1 元 / 万字符**（cosyvoice-v3-flash） |
| 免费额度 | **1 万字符**，开通后 90 天内有效 |
| 一个故事成本 | 10 页 × 约 80 字 = 800 字符 ≈ **0.08 元** |

也就是说：**免费额度够你生成约 120 个故事**，之后一个故事 8 分钱。

比 Edge TTS 贵一点，但 Edge TTS 音色区分不开，等于白做。

> 官方计费页：https://help.aliyun.com/document_detail/2987148.html

## 五、几个已知限制

1. **单次文本不超过 2000 字符**
   代码里已自动截断到 2000 字，正常单页故事不会超。

2. **限流 180 次/分钟**
   代码是**逐页顺序生成**的，不会触发限流。改并发的话要注意。

3. **只支持北京地域**
   API Key 必须是华北 2（北京）的，新加坡的 Key 用不了 CosyVoice。

4. **`·` 符号会念错**
   cosyvoice-v3-flash 官方已知问题，遇到「·」分隔的数字会漏读。
   代码里已自动把 `·` 替换成中文逗号规避。

## 六、出问题怎么办

**没配 Key / Key 失效时会怎样？**
自动回退到原来的 Edge TTS，**功能不会挂**，只是音色区分度回到从前。后端日志会有提示。

**怎么看后端日志？**
```bash
docker compose logs -f backend
```
看到 `[TTS] 阿里云 xxx 失败 401` 就是 Key 有问题。

**音色不对 / 想换音色？**
改 `backend/src/lib/tts.ts` 里的 `ALIYUN_VOICE` 表，把 voice 参数换成你想要的。
完整音色列表：https://help.aliyun.com/zh/model-studio/cosyvoice-voice-list

改完记得**清一下音频缓存**（否则还是老声音）：
```bash
rm -rf backend/data/tts/*.mp3
```

## 七、代码改动位置

| 文件 | 改了什么 |
|---|---|
| `backend/src/lib/tts.ts` | 新增阿里云合成、音色映射表、双端点容错、文本预处理 |
| `backend/src/modules/tts.ts` | 新增 `/api/tts/provider` 自检端点 |
| `backend/.env.example` | 新增 TTS 配置项说明 |
| `backend/docker-compose.yml` | 透传 TTS 环境变量（从 `backend/.env` 读取） |
| `render.yaml` / `railway.json` | 预留 TTS 环境变量槽位（填了才生效） |
| `frontend/src/types/story.ts` | 新增 `VOICE_HINTS`（音色特征说明） |
| `frontend/src/pages/Create.tsx` | 音色选择器下方显示声音特征 |

**容错设计**：端点（Workspace 专用 / 标准 DashScope）× 音色（主音色 / 备用音色）共 4 种组合依次尝试，
任一层失败都自动降级；最终全部失败才回退 Edge TTS，保证语音功能始终可用。
